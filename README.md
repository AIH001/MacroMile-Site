# MacroMile Site

The static MacroMile marketing and support website. Built with plain HTML, CSS, and JavaScript; no build step is required.

## Vercel

Import this GitHub repository into Vercel. Select **Other** as the framework preset and leave the build command empty. The repository root contains `index.html`, the support page is at `/support/`, and the privacy policy is at `/privacy/`.

## Local preview

Serve the repository root with any static HTTP server (for example, `python3 -m http.server`).
